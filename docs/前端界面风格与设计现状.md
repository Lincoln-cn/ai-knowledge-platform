## 一、定位与谱系

| 维度 | 现值 |
|---|---|
| 品类 | 企业级 **B2B / 后台 / 开发者工具**（知识助理平台：RAG 问答 · 知识库 · 应用编排 · 权限） |
| Genre | `modern-minimal` |
| 主题 | **Cobalt** —— 冷调工程白纸 + **发丝线分面** + **一个**电光钴蓝信号色 + 6px 紧圆角 |
| 结构族（Macrostructure） | **Workbench**（应用页）· **带框顶栏**（应用外壳）· 沉浸页复用 Workbench 但允许一次深色拍子 |
| 生成方式 | Hallmark（首次运行 + 两轮 redesign），2026-09-25 |
| 设计立场 | 深度靠**线**与**色阶**，不靠投影；克制，但要求**每页有一个焦点**（仪器面板 / ⌘K / 深色石墨带） |

**一句话概括现在的观感**：一张冷色工程图纸。页面几乎全是「白纸 + 1px 发丝线 + mono 小标签 + 等宽数字」，颜色只有一种蓝，其余是四级灰阶；少数几处深色石墨块用来"报警/报数"。

## 二、设计令牌（`frontend/tokens.css`）

### 2.1 色板 —— 全部 OKLCH，色相锚在 252–260（冷），**没有纯白、没有零彩度灰**

**表面（4 档 + 1 hover）**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-paper` | `oklch(97.4% 0.004 252)` | 画布底（`main` 背景） |
| `--color-surface` | `oklch(99.4% 0.002 252)` | 卡面 / 浮层 |
| `--color-surface-2` | `oklch(99.8% 0.001 252)` | 最上层浮层：抽屉、弹窗、下拉 |
| `--color-sunken` | `oklch(95.8% 0.005 252)` | 凹槽：表头、输入框、代码块、调试抽屉顶栏 |
| `--color-hover` | `oklch(96.8% 0.006 252)` | 行 / 菜单项 hover |

**线（3 档，分面全靠它）**：`--color-rule` 90.5% ｜ `--color-rule-2` 94% ｜ `--color-rule-strong` 85%（输入框边）

**文字（4 档）**：`--color-ink` 24%（标题）｜ `--color-ink-2` 38%（正文）｜ `--color-muted` 56%（次要）｜ `--color-faint` 68%（占位/禁用）

**信号色（唯一）**：`--color-accent: oklch(58% 0.2 256)`（电光钴蓝）· `-hover` 52%/0.21 · `-ink` 99%（压在蓝上的字） · `-soft` 96%/0.028（选中行底） · `-line` 88%/0.055（选中边） · `--color-focus` = accent
> ★ **accent 用量上限：任一视口 ≤ 5%。** 只许出现在：选中态左竖条 / 输入焦点环 / 链接 hover 下划线 / **一个**主按钮 / 状态点。

**状态语义（3 + soft）**：`ok` `oklch(55% 0.115 158)` · `warn` `62% 0.13 72` · `danger` `55% 0.17 27`，各带一个 `-soft`（96.5% 底）。**只用于标签、圆点、行内文字，不做大面积填充。**

**深色石墨拍子（一页只许一处）**：`--color-graphite` 22%/0.016/260 · `-2` 27% · `-ink` 93% · `-ink-2` 78% · `-muted` 66% · `-faint` 60% · `-rule` 33%

**投影只有两档**：`--shadow-whisper: 0 1px 2px …/0.05` · `--shadow-float: 0 4px 16px …/0.08`

### 2.2 字族 —— **2+1 三面封顶**（第四个字族就是 slop）

```
--font-display : 'Space Grotesk' + CJK 栈   → 页标题、品牌字、大数字
--font-body    : 'Geist'         + CJK 栈   → 正文 / 界面默认
--font-mono    : 'JetBrains Mono'           → 数字列、ID、版本号、接口路径、全大写小标签
--font-cjk     : PingFang SC → HarmonyOS Sans SC → Microsoft YaHei → Source Han Sans SC → Noto Sans CJK SC
```
拉丁面**自托管**且只含 latin 字形（`unicode-range` 显式声明），汉字逐字形回退到本机 CJK 栈；`font-display: swap`。

### 2.3 字号阶梯（14px 基准；单页最多用 5 档）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--text-2xs` | 12px | 元信息、密集表格、mono 小标签（**中文下限**） |
| `--text-xs` | 13px | 次要正文、表格单元格 |
| `--text-sm` | 14px | **正文 / 界面默认** |
| `--text-md` | 16px | 强调正文、卡片标题 |
| `--text-lg` | 20px | 区块标题 |
| `--text-xl` | 24px | 页面标题 |
| `--text-2xl` | 32px | 品牌字 |
| `--text-3xl` | 40px | 仅登录页深色拍子 |

**字重**：正文 400；标题与正文对比 ≥ 300（正文 400 ⇒ 标题 600/700，不用 500）。display 600 / body 400 / 强调 500。

### 2.4 行高 · 字距 · 间距 · 圆角 · 动效 · 层高

**行高两档（不许一刀切）**：`--leading-ui: 1.6`（表单/表格/标签/密集列表，"扫"）· `--leading-body: 1.75`（markdown/消息体/说明段落/`.notice`，"读"，用全局 `.prose`）· `--leading-title: 1.3` · `--leading-tight: 1.5` · `--leading-display: 1.15`
> 实测依据：把 1.75 一刀切套在 body 上 ⇒ 编排画布 9 张节点卡各被撑高，整图 1004px 而可视区 795px，**2 个节点被切出可视区**。

**字距**：`--tracking-display: -0.02em`（**仅拉丁/数字**）· `--tracking-label: 0.08em`（mono 全大写小标签）· `--tracking-body: 0`（**中文标题必须为 0**）· 仪器面板内标签收半档 `--tracking-label-instrument: 0.06em`

**间距（4pt 刻度，九档，按角色命名）**：`2 · 4 · 8 · 12 · 16 · 24 · 40 · 64 · 96 px`（`3xs → 3xl`）。页内边距 `--space-lg`，区块之间 `--space-xl`，卡片内边距 `--space-md ~ lg`。同级兄弟用 `gap`，不用成串 `margin`。

**圆角（紧，像用尺子画的）**：`xs 3` · `sm 4` · **`--radius 6`**（按钮/输入/标签 —— Cobalt 签名，**不是胶囊**）· `lg 8`（卡片/面板）· `pill 999`（**只给头像与圆点**）· `--radius-instrument 10`（仪器面板，比卡片松一档）

**动效**：`--ease-out cubic-bezier(0.16,1,0.3,1)`（进入）· `--ease-in (0.7,0,0.84,0)`（离开）· `--ease-in-out (0.65,0,0.35,1)`（切换）；`--dur-micro 120ms`（按下/勾选/颜色）· `--dur-short 220ms`（hover/下拉/提示）· `--dur-long 420ms`（抽屉/弹窗/登录页那一次入场）。
**只动 `transform` 与 `opacity`**；禁用浏览器默认 `ease`、bounce/overshoot、视差、无限循环；焦点环**瞬间出现不做过渡**；必须有 `prefers-reduced-motion` 分支（全局已有一条）。

**层高（六级 + 两个专用档）**：`base 1 · raised 10 · dropdown 100 · sticky 200 · modal 400 · toast 500 · tooltip 600`；另有 `--z-canvas 6000`（画布内部件，LogicFlow 自己用到 5000）与 `--z-cmdk 3000`（命令面板：盖住抽屉弹窗，低于画布内部层）。

## 三、骨架：外壳与导航（`src/pages/_shell/Index.vue`）

**带框顶栏**（Cobalt 签名 5）——**不用左侧 rail**：

```
┌─ topbar (h 48px, 全工程唯一允许 backdrop-filter 处) ──────────────────────────┐
│ 字标(几何标记+平台名) │ 竖发丝线 │ [工作台][对话与知识▾][配置与运营▾][管理▾]  │ grow │ [ctrl K] [开始对话(主按钮)] [头像 姓名 角色▾] │
└───────── border-bottom: 1px --color-rule-2（滚动后收紧为 --color-rule）──────┘
                                   main（--color-paper，唯一滚动容器）
```

- **导航 = 3 组 11 项 + 「工作台」**（分组菜单下拉，不平铺）：对话与知识（对话 / 知识库 / 应用市场 / 应用管理）· 配置与运营（提示词 / 模型管理 / 运营看板 / 反馈处理）· 管理（基础数据 / 组织机构 / 系统管理）。
- **菜单项过滤走唯一判据 `canReach()`**：同时管**权限点**（`meta.permission`）与**数据范围**（`meta.scopeForms`）；空组连标题一起去掉。外壳、命令面板、403 页、工作台入口共用同一函数（防"某入口在 A 处隐藏、B 处仍可见"）。
- **键盘可达**：分组触发 ↑↓ 进菜单 · 菜单内 ↑↓ 循环 · Esc 两级关闭并归还焦点 · Tab 关菜单不吸焦点 · 点外部关闭。
- 右侧：**带框的 `ctrl/⌘ K` 提示**（mono 大写，可点，等同按键）→ **一个实心钴蓝主按钮**（"开始对话"）→ 用户下拉（我的账号 / 修改密码 / 退出登录）。
- `main` 是唯一滚动容器；顶栏 `position: sticky` 语义靠 `scrolled` 状态切换。

**路由**：`routes.ts` 用 `import.meta.glob('../pages/*/route.ts')` **自动发现**各模块子路由（新增模块不改注册表）；沉浸页（登录、公开问答）必须在此显式合并。403 与 404 **挂在壳内**（保留顶栏与入口）；未登录的裸 404 挂在 `/404`。

## 四、页面族与结构基线

### 4.1 应用页（绝大多数页面）—— Workbench

```
.page（padding --space-lg, flex column, gap --space-md）
 ├ 页头：标题 + 元信息/说明行 + 右侧操作区（一律左对齐，不居中）
 ├ 说明带：.notice（info / warn / err）—— 用完整发丝边框 + 一个小状态方点，**没有左侧彩色粗条**
 ├ 过滤条：.filters.panel（搜索框 + 分段/下拉 + "共 N 个"）
 ├ 主体：卡片网格 / 表格 / 主从双栏 / 表单
 └ （至多一条）仪器面板 InstrumentCard —— 深色石墨，本页的焦点
```
**禁令**：没有 hero、没有两端 CTA 条、没有滚动入场、没有三列等宽"图标在上-标题-两行文案"功能格子、没有卡片套卡片。

### 4.2 沉浸页（登录 / 公开问答）

复用同一套令牌，但允许用掉本页**唯一那一次深色石墨拍子**：
- **登录页**：左栏深色石墨（叠层英雄构图：一片有机色场 + 极细颗粒衬在文字后）+ 右栏浅色表单；底部一条 `.notice info` 说明当前走 mock 还是真后端。
- **公开问答页**（`/public`…）：深色页头带（app 名 + 冻结密级上限）+ 推荐问题 chips + 消息列表 + 引用边注；凭证异常分**四态**呈现（状态标签 + 为什么 + 怎么办）。

### 4.3 编排画布（`pages/workflow/**`）—— **唯一豁免「零装饰」的区域**

LogicFlow + `@antv/layout`：节点卡、连线、网格背景都算**功能件**。结构是「顶部工具条（返回 / 应用名 / 版本；添加组件 · 保存 ｜ 发布（唯一主按钮） ｜ 更多）+ 主画布 `flex:1`（不用 100vh）+ 右抽屉（发布历史）+ 下拉浮层（添加组件）」。
**注意**：这一块是从旧工程移植的（自带 `--app-*` 别名层与 `.top` / `.workflow-main` 类名），值虽指向令牌，但排版节奏与宿主页面族不同源。

## 五、视觉语汇与组件

| 语汇 | 实现 | 要点 |
|---|---|---|
| **发丝线** | `.rule` / `.rule-2`；面板 `1px --color-rule` + `--radius-lg` | 这是 Cobalt 的**核心动作**：分面靠线不靠影 |
| **页头** | `PageHeader.vue`（标题 + desc + `#actions` / `#after-title` 插槽） | 页头通栏底铺**蓝图细网 hatch**（伪元素 + `inset:0` + `multiply`，`opacity: --art-opacity-hatch` 0.12）——**每页一条带，等于页头自己的盒高** |
| **面板/卡片** | `.panel` / `.card` / `.panel-head` / `.panel-body` | 一层容器，不套娃；一级标题 `--text-lg` |
| **提示块** | `.notice` `.info` `.warn` `.err` | 改掉了「左侧彩色粗条」（被点名的 side-stripe 反模式）：现在是完整发丝边框 + 5×5 状态方点，**语气靠文字不靠色块** |
| **状态点** | `.dot` + `.ok/.warn/.err` | 6px 圆点，行内用 |
| **空态** | `.empty` / `.empty-title`；进阶 `EmptyArt.vue` | 默认**只用排版 + 一条发丝线，不插画**；进阶版是「mono 线稿示意图 + 极浅色场」，且**必须两栏（图偏一侧、字在另一侧），不许居中大图** |
| **标签** | `el-tag`（`effect="plain"`）+ `--radius-sm` | 小、方、平，**不用彩色填充** |
| **表格** | `el-table` | 表头吃 **mono 小标签**；去 EP 投影、分面交给发丝线；数字列 `tabular-nums` |
| **按钮** | 主 = 实心 accent（**6px 圆角，不是胶囊**）· 次 = 1px `--color-rule-strong` 描边透明底 · 文字 = accent 无边框 hover 下划线 | 一行里**最多一个**主按钮；hover **不抬升**（每个卡片都浮起来是被点名的模板动作） |
| **输入** | 1px 线 + 6px 圆角；hover 换线色、聚焦只换边色 + 焦点环 | 禁止绕开令牌直接写 `--el-*` |
| **弹窗/抽屉/气泡/消息** | 一律 `1px --color-rule` + `--radius-lg`（气泡 `--radius`）+ `--shadow-float` | 深度主要仍靠线 |
| **命令面板** | `CommandPalette.vue` | `Teleport` 到 body · `role="dialog"` `aria-modal` · 焦点开/还 · Esc 与点遮罩关闭 · ↑↓ 选择 · 输入过滤 · 顶栏有带框提示 |
| **仪器面板** | `InstrumentCard.vue` | 深色石墨 + mono 标签（0.06em）+ 等宽读数 + 右上角**四态胶囊**（OK/RUNNING/WARN/ERROR，1px 同色描边不做填充）+ 一片 hatch（`screen`，上限 0.6 档） |

**当前调用点**：`InstrumentCard` → 工作台、知识库详情、应用概览抽屉（3 处）；`EmptyArt` → 分段面板（`pipeline`）、会话消息列表（`retrieval`）（2 处）。

## 六、四个「签名动作」

1. **仪器面板（签名 4 + 8）**：深色石墨的"机器回执"，回答「这台机器此刻在做什么」。**每视口上限一个**；**数据必须真实**（`analyticsApi` / `ingestionApi` / `assistantsApi`），**编造指标是本系统最严重的违规**；圆角 10px；只一条极轻抬起。
2. **深色石墨带（签名 8）**：从"仅沉浸页"放宽到"**每页至多一条**"，用途固定为「机器回执 / 展示时刻」。判据：**去掉它，页面会失去一个读数**；若什么都没少，它就不该在。
3. **命令面板（签名 5）**：`⌘K / Ctrl+K` **真的能用** —— 跳页（按权限过滤、与顶栏菜单同源）+ 动作（建知识库 / 建应用 / 开始问答）。
4. **有界 art 层**：**限定表面，不放开风格**。允许位图的地方是穷举的：

| 表面 | 形态 | 上限 |
|---|---|---|
| 沉浸页 | 一片有机色场，**偏向一侧**（禁居中） | 每页 1 片 |
| **页头通栏底**（每个应用页都有） | **蓝图细网 hatch**，`multiply` | 每页 1 条带，≤ `--art-opacity-hatch` 0.12 |
| 空态 | mono 线稿示意图 + 一片极浅色场 | 每空态 1 组 |
| **石墨带内** | hatch，`screen` | 每带 1 片，≤ 0.6 × `--art-opacity-screen` |
| 沉浸页深色栏内 | 极细颗粒 grain | 1 片，≤ `--art-opacity-grain` 0.15 |

**为什么页头用 hatch 而不是 wash**：wash 是"区块强调"，而页头**每页都有** ⇒ 铺 wash 等于做了全局处理；**纹理允许平铺，色场只许出现在沉浸页与空态**。
**素材是本地生成的位图**（源 SVG 在 `src/assets/art/src/`，`tools/rasterize_art.py` 用已装的 Playwright 栅格化）——**不走任何外部 CDN**；单文件 ≤ 200 KB，全目录 ≤ 1.2 MB。
**用量纪律（实测得来）**：① 任何 `cover` 直铺都会露出硬边矩形 ⇒ 正解是 `mask` 强制四边归零 + 放大对准素材能量团（判据：**紧贴元素边界内外的相邻像素差应为 0**）；② `--art-opacity-*` 是**元素 opacity 上限**，不等于视觉强度上限 —— **先量像素再顶上限**。

## 七、中文排印四纪律（照搬英文配方会出错）

1. **正文字号保底 14px**（`--text-sm`）；12px 是中文下限（`--text-2xs`）。11px 一律抬到 12px。
2. **行高分两档**：阅读性文本 ≥1.75（`.prose` / `.notice`），界面 1.6。一刀切 1.75 会把密集界面撑爆（见 2.4 的实测）。
3. **中文标题字距必须为 0**（拉丁 display 的 `-0.02 ~ -0.04em` 会让汉字笔画相撞）。负字距只许加在纯拉丁/数字上。
4. **不用 `font-style: italic`**（中文没有真斜体，会得到机械倾斜的糊字）。强调一律用**字重 / accent 色 / 下划线**。

**标点**：中文用「」，英文用 “ ”，破折号 ——，省略号 …；不写 `--` 与 `...`。
**mono 只许占两处**：① 全大写小标签（页头元信息、表头、状态、kbd 提示）② 数字列 / ID / 版本号 / 接口路径。

## 八、反模式清单（现状明确禁止的）

**Token 层**：纯 `#000` / 纯 `#fff` · 灰阶零彩度（每个中性色带 0.004–0.020 冷色彩度）· 紫→蓝/青渐变 · 渐变文字 · 毛玻璃（`backdrop-filter` 只许顶栏一处）· 彩色左/右粗条 callout · 投影堆叠。

**结构与排版**：居中大标题 hero · `min-height: 100vh` 的居中单句 · 三列等宽「图标在上-标题-两行文案」功能格子 · 卡片套卡片 · 每个区块都滚动淡入 · 卡片内边距 = 区块间距 = 页面边距（扁平节奏）。

**交互与工程**：**节点/画布内部浮层不许写 `:teleported="false"`**（popper 进 `foreignObject` ⇒ 用户选不了 ⇒ 必填永远填不上，踩过）· 页面不许直接写 `--el-*` / `--el-color-primary`（等于绕开系统）· 不许内联色值 / 字族 / 裸 px（`check_design.py` 抓）· **emoji 不许塞进 `img` 的 `src`**（图标字段是 emoji 字符串）· 可逆动作不做确认弹窗（乐观删除 + 可撤销），不可逆才用弹窗 · **静默成功**（能看见结果的动作不弹成功提示，提示只留给失败 / 异步且结果不可见 / 需要留痕的确认）· 不写 `transition: all` · 不写浏览器默认 `ease`。

## 九、工程约束（设计改动必须落在这些约束里）

- **令牌是单行道**：`tokens.css`（定义）→ `index.css`（基线/原子类）→ `element-plus.css`（`--el-*` 单向映射）。**页面里每一个颜色、字体、间距都必须写 `var(--token)`。**
- **契约冻结**：页面只从 `@/api` import，绝不直接引 `@/lib/http`；**mock 只住在传输层**（`VITE_USE_MOCK` 是唯一开关，切后端页面代码一行不改）。
- **依赖白名单**：`element-plus` · `@element-plus/icons-vue` · `pinia` · `vue-router` · `axios` · `dayjs` · `lodash-es` · `mitt` · `echarts` · `@logicflow/*` · `@antv/layout`。**不得引入**商业基座框架及其 CRUD 模板产物、`vuex`、`moment`、非 ESM 的 `lodash`、任何外部 CDN（字体与素材自托管）。
- **权限声明只有一个点**：`RouteMeta.permission` 是路由级门禁唯一声明处（守卫拦不拦、菜单显不显、工作台入口显不显都读它）。**不给导航项另加权限字段。**
- **图标字段是 emoji 字符串**，不是 URL。
- **弹窗一律 `append-to-body`**（否则被 LogicFlow 的 `foreignObject` 裁掉）。

## 十、闸门：这些约束怎么被守着

`check_design.py` 逐文件扫描 `src/**`（注释与 HTML 注释先剥掉；真源文件不计分；孤儿文件单列），**14 个维度全部要求为 0**：

`内联色值` · `关键字颜色` · `内联 font-family` · `字号<12px` · `斜体` · `彩色左/右粗条` · `100vh` · `z-index>=1000` · `渐变文字` · `transition:all` · `浏览器默认ease` · `旧令牌引用` · `teleported="false"` · `emoji 塞进 img`

外加一组**非令牌口径断言**（同样在这道闸门里）：引用卡片的来源标签必须按**结构性判据**（缺 `kbId` = 会话域）切换，会话域不许出现「跳转到分段管理」。

`check_theme.py`：读**运行时计算值**，证明令牌桥真的生效（EP 按钮不再是 `#409eff`），以及字体分工落地（body=Geist+CJK、表头=JetBrains Mono、数字列 `tabular-nums`）。

其余防线（见 `frontend/README.md` 六条防线）：`vue-tsc` 类型 · `vite build` 模板语法 · `verify_refs.py` 跨模块 id 悬空 · `verify_features.py` 功能点 · 真栈闸门（`check_flow_walkthrough.py` 逐页走查 12 页等）。

## 十一、现状诊断 —— 设计改进的起点

### 11.1 已经做扎实的部分（改进时**不要**动）

1. **令牌化程度高**：色/字/距/圆角/动效/层高全部具名，EP 的 `--el-*` 由一处单向桥接，"同屏三种蓝"这类问题在机制上被消除。
2. **中文排印有立场且有实测**：四条纪律不是口号，每条都附了后果（1.75 一刀切撑爆画布节点、负字距撞笔画）。
3. **无障碍基础件齐**：全局 `:focus-visible`（且**不写 border-radius** —— 避免聚焦时元素变形）、全局 `prefers-reduced-motion`、菜单与命令面板的完整键盘/ARIA 语义、hover 800ms / focus 0ms 的提示时序。
4. **状态语义克制且清楚**：状态色只做标签/圆点/行内文字；**错误态与空态严格分开**（多处显式注释"不许把加载失败渲染成还没有"）；失败文案给**原因 + 下一步 + 重试**。
5. **分面的语言统一**：全站靠 1px 线与四级色阶分区，没有投影堆叠与卡片套卡片。
6. **每页一个焦点**的机制存在（仪器面板 / ⌘K / 深色带 / 页头 hatch）。

### 11.2 自己跟自己不一致的地方（**可核对**，是改进最该先动的）

| # | 现象 | 证据 | 影响 |
|---|---|---|---|
| 1 | **页头有两套，且有一套绕开令牌** | 只有 `overview/Index.vue` 用全局 `.page-head` + `.h1`（**24px** = `--text-xl`，padding `--space-lg`）；其余 **12 个页面**用 `PageHeader.vue`，它写的是**裸值**：`font-size: 17px`（**不在字号阶梯里**）、`gap: 16px`、`margin-bottom: 14px`（14 不在 4pt 刻度）、`line-height: 1.7`（不走 `--leading-*`）、`margin: 5px 0 0` | 同一层级界面的"页面标题"在 24px 与 17px 之间摇摆；页头是全站唯一一处**既脱阶梯又脱令牌**的组件 |
| 2 | 文档漂移：`router/routes.ts` 仍在讲「**侧栏**导航」「**侧栏**显不显」 | 外壳早已是带框顶栏（design.md § Macrostructure 明写"不再用左侧 rail"） | 新读者按注释去找侧栏 |
| 3 | 孤儿样式文件仍在仓库 | `src/pages/workflow/styles/element-plus.scss`（**零处 import**），里面是旧色板（含 `#3370ff`） | `check_design.py` 专门给它开了 `[孤儿]` 命名空间计数 |
| 4 | 编排模块仍有"猜高度" | `workflow/styles/variables.scss`: `--app-main-height: calc(100vh - 56px - … - 40px)`；`AddDatasetDialog.vue`: `height: calc(100vh - 560px)` | 闸门只抓 `height/min-height: 100vh`，**抓不到 calc 里的 100vh**（盲区）；而项目自己的口径是「`calc(100% - Npx)` 都是在猜兄弟宽度」 |
| 5 | 编排画布与页面族**不同源** | 画布自带 `--app-*` 别名层、`.top` / `.workflow-main` 类名、17px 小标题、文字按钮密集排列（旧工程移植）；design.md 只给了它"豁免零装饰"，没给"排版对齐"要求 | 从应用管理点进"编排"会感到换了一套产品 |
| 6 | 品牌层是占位 | design.md § Brand 自陈「现在的『知』字方块 + 文本是占位」；`public/` 目录不存在、`/favicon.ico` **404**（全站唯一一条 console error） | 第一眼与浏览器标签页上都是占位物 |
| 7 | art 层的**可见覆盖不均** | `EmptyArt` 只在 2 处（分段面板、会话消息列表），`InstrumentCard` 只在 3 处（工作台、知识库详情、应用概览抽屉） | 除工作台/知识库外，"每页一条深色带"的签名动作没有落点；design.md 里逐页落点表写着登录/公开页"已有" |
| 8 | design.md 的计数与实际不符 | 文档写"13 个业务模块"，实际导航 **3 组 11 项 + 工作台** | 计数会腐烂（README 里也自陈过同类问题） |
| 9 | 闸门量度有已知盲区 | `字号<12px` 只抓下限 ⇒ **17px 脱阶梯抓不到**；**裸 px 间距完全不抓**；`font-family` 抓内联字族但抓不到裸 px 行高 | 上表第 1 条正是从这个盲区里漏过来的 |

### 11.3 观感层面的自评（主观，供设计者参考）

- **强**：秩序感、可信感、数据密度控制得好；mono 小标签 + 等宽数字让"企业工具"的气质很到位。
- **弱**：**戏剧性与焦点分布太靠前**——工作台是最"有设计"的一页，往里走（模型管理、系统管理、基础数据）逐渐退化成"一排卡片/一张表格 + 一片空白"，容易读成"没有设计"。设计系统自己写过这句判据：**「克制不带焦点，等于没有设计」**。
- **弱**：**层级过平**。因为只有 5 档字号 + 一种强调色，页面内部（区块标题 / 卡片标题 / 正文）常靠"字重 400→500"区分，远看是一片均匀的灰。深色带是唯一的"重音"，但它只出现在 3 处。
- **弱**：**空态与加载态的表达手段少**（默认只有排版 + 发丝线），大量页面因此显得"空而无话"。
- **弱**：**深色石墨（唯一的高对比素材）利用率低**：三种页面形态里，只有沉浸页与 3 处仪器面板用到它。
