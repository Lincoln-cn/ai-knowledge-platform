## 一、忠实度抽查表（每条答案逐句判）

**判定口径（摘自 `13 §12.13` ②，冲突以那边为准）**：
- **断言** = 答案中可判真假的陈述；事实陈述 / 数值阈值 / 结论句 / 建议祈使**都算**；过渡修辞、`[N]` 引用标记本身**不算**。
- **有依据** = 该断言的内容能从**它引用的段落原文**推出（同义改写算）。
  **不算**有依据的三种：引用只提到话题不含该结论 · 结论要跨多段拼接但只引一段 · 结论超出引用范围。
  一条断言引多段时**任一段能支撑即算有依据**；**没引任何段落 ⇒ 直接算无依据**。

## 二、噪声敏感度抽查表（同一批 20 个问题，各跑两遍）

**做法**：同一批 20 个问题各跑两遍 —— **A 遍**正常上下文，**B 遍**在上下文里**混入 2–3 段无关段落**
（从别的知识库 / 无关主题里挑，长度与真实段落相当），其余全不变。比较两遍答案，判是否变差。

| 编号 | 问题 | A 遍（正常）答案要点 | B 遍（加噪）答案要点 | 是否变差（是/否） | 变差表现 | 判定人 | 判定时间 | 备注 |

| N-01 |  |  |  |  |  |  |  |  |

| N-08 |  |  |  |  |  |  |  |  |

| N-10 |  |  |  |  |  |  |  |  |

> **「变差」算什么**：出现 A 遍没有的编造断言 · 原有断言被无关段落带偏（改口 / 加了无关限定）·
> 答非所问 · **把无关段落的内容当成了答案**（最常见的变差形态）。
> **不算变差**：措辞不同但要点一致 · 多引用了一段但结论没变。
> 「变差表现」那格写**具体哪一句**，不许只写"变差了" —— 归因要靠它（issue `#87` 危害②）。

## 三、填写说明（★ 两人独立判 + 记一致率）

1. **两人独立判，先不商量**：甲乙各自把两张表填完（判定人栏写自己的名字），**填完之前不许对答案**。
2. **判完才对齐，记一致率**：逐格比对，一致的格数 ÷ 总格数 = **一致率**，写在表末的「汇总」里。
   - ★ **一致率本身就是"口径清不清晰"的读数**：低于 0.8 说明 `13 §12.13` ② 的「断言 / 有依据」边界还有含糊处，
     **先改口径、再重判**，不要先平均出一个数了事；
   - 不一致的格子**必须在备注里写清各自理由**，这些理由就是下一轮订正口径的输入。
3. **谁都不许拿"答案读起来很顺"当依据** —— 判的是「这句能不能在引用里找到依据」，不是「这句像不像真的」。
   ★ **要防的是"引用真实段落却推出段落里没有的结论"**（这正是 B1/B3 看不见的那种坏）。
4. **故意造一条坏的当自检**（issue `#87` 判据③「抽查要能红」）：正式抽查前，先手工造一条
   **「引用真实、但结论超出引用」**的答案混进去，两位判定人都必须把它标成「否」——
   **标不出来 = 这张表不可信**，先修口径再验收。
