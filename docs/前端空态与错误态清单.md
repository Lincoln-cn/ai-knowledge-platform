# 前端空态与错误态清单（F4）

> 建表：2026-11-01。判据只有一句：**「没拉到」与「没有」必须能分清**。
> 外部用户对这两者的容忍度极低 —— 把失败渲染成空态，他会以为数据没了，而实际上重试一次就好。

## 一、三种形态（判据按形态给，不按页面）

| 形态 | 做法 | 什么时候合适 |
|---|---|---|
| **A** 页面级错误块 | 内容区被一个独立的错误块占住（含原因与重试），列表根本不渲染 | 页面主体只有一组数据 |
| **B** 空态内二选一 | 表格/列表的 `#empty` 插槽里先判错误，再判空 | 数据源是表格，空态本身就是一块位置 |
| **C** 只弹 toast | catch 里 `ElMessage.error(...)`，列表照样渲染成空 | ❌ **不允许**：错误伪装成空态 |

★ C 类不是"体验差"，是**读数错误**：用户据以判断"库里没东西"。

## 三、本批唯一的一处修补（C → B）

**`pages/basedata/components/DictionaryPanel.vue`**：`load()` 失败原来只 `ElMessage.error(...)`，`list` 保持空 ⇒ 表格空态渲染成「还没有密级」。字典是**四类共用面板**，所以这一个缺口在四个 tab 上各出现一次。

改法：

1. 加 `const loadError = ref<string | null>(null)`；
2. `load()` 成功时清空它，失败时**先清 `list` 再记原因**（避免旧数据与错误态同时在场）；
3. `#empty` 插槽里 `v-if="loadError"` ⇒ 错误块（原因 + 重试按钮）；`v-else` ⇒ 原空态。

## 四、结论

- 除基础数据面板外，**没有发现 C 类残留**。清单里的 A/B 都是既有实现，不是本批新做的 —— 所以本批的交付是**这张表 + 一处修补**，不是"重写了 14 个页面"。
- ★ 盘点方式值得记住：先用 `#empty` 插槽与错误变量名做两轮 grep 得到候选，再**逐页读 catch** 定形态。第一轮 grep 用 `loadError` 做关键词时，把 `listError`（知识库）与 `error`（反馈/看板）全漏了 —— **靠一个变量名惯例去盘点，会把"用了别的名字"读成"没做"**。
