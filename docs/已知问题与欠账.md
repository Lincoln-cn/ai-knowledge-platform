## A 类：★「看起来在做、实际没生效」—— 本项目最贵的病

| # | 现象 | 根因 | 现状 |
|---|---|---|---|
| A1 | 建库向导「生成预览」整条不可用 | 走的是 mock 时代的**暂存上传**链（`stageUploads → uploadIds`），而 `/uploads` 从未实现 ⇒ 真栈 `documentId` 恒为 `null` ⇒ 必然 400；失败还被 `catch { uploadIds = [] }` 吞掉 | ✅ `5fc7af9` |
| A2 | 长标题把整篇建档打挂（500） | 域侧标题上限 **256**、库列 `varchar(255)` ⇒ 差 1 个字符就 `value too long`，整篇建档 500 | ✅ `b18259c`（域侧夹 + V17 放宽到 512） |
| A3 | **闸门假绿灯** | `check_knowledge_form.py` 用 `"字" in body` 判"预览能看到分段" —— 页面别处的「1200 字」就能蹭过 ⇒ **A1/A2 一直没被发现的原因** | ✅ 改精确信号（`.preview-item` 计数 + 「共 N 段」） |
| A4 | 走查脚本**什么都没测却像跑过了** | ① `check()` 返回 `None`，调用处 `if not check(...)` 恒真 ⇒ 第一步就退出 ② 同文件 `self_tier` 未定义 ⇒ 第一页 `NameError` ③ 断言看控制台错误、消息报的却是失败接口数 | ✅ 修好，并加"看输出行数"这条判据 |
| A5 | 分段面板 `modelLimit` **永远停在写死的默认值** | 「全部文档」时 `documentId` 传 `null`，而契约要求预览必须给 `documentId` 或 `segmentationPlan` ⇒ **每次一个注定 400 的请求**被 `catch {}` 吞掉 | ✅ `ac90e9a` |
| A6 | **我自己**：镜像里启动日志没有 OCR 那行，一度以为"探测没生效" | 镜像是 `COPY target/*.jar` 建的，而那个 jar 是**加 `OcrEngine` 之前**打的（那几轮只跑了 `test-compile`） | ✅ 重打包后一次通过 |
| A7 | `docker build .` **卡住不动、25 分钟零输出** | 仓库根有 **25 GB** 的 `_archive/`（`.gitignore` 忽略、不进版本库，但本机在），没有 `.dockerignore` ⇒ 上下文全量推给守护进程 | ✅ 裁剪后 25 GB → **490 MB** |

**这一类的判据（反复用得上的）**

> **先确认三件事：我验的是不是最新产物 · 是不是真链路 · 守住了没有。**
> · 最新产物：比对 `target/*.jar` 的 mtime 与源码 mtime，或直接在产物里 grep 新类名（A6）
> · 真链路：mock 闸门绿 ≠ 真栈绿（mock 长期比真后端宽松）
> · 守住了没有：**闸门自己的返回值是它最容易骗过人的地方**（A3/A4）

## B 类：照文档 / 照旧版本抄会踩的框架口径

| # | 现象 | 真相 | 出处 |

| B1 | 跨模块端口被判越界 `depends on non-exposed type` | Modulith 的 `@ApplicationModule` **默认 CLOSED**：模块子包不对外暴露 ⇒ 跨模块 SPI 放 **`platform`** | `0.3.0` |
| B2 | 一批 4 段文本，上游只回 1 个向量 | 手拼 payload 的 `escape()` 只转义 `\\` 与 `"`、**不转义换行**，而 `search_text` 恰好含换行 ⇒ 报文非法 | `0.3.0` |
| B3 | 桩服务把非法请求体**静默吞掉** | `_read_json` 已标记 `__unparsable__`，处理函数没查 ⇒ 当成"一条空文本"返回 **200 + 1 个向量**，掩盖客户端 bug | `0.3.0` |
| B4 | `Error parsing OCRStrategyAuto` | 3.3.1 的 `setOcrStrategyAuto(String)` 要 **`"num[%], num"`**（如 `"10, 10"`），**不是**设计册抄自 Tika 4.0 的 JSON 块 | `2f0cbce` |
| B5 | 拿 `parser.getLangs()` 判断"语言包装没装"得到**假红灯** | 3.3.1 的 `getLangs()` 读的是 **Tika 自己的** tessdata 位置、返回空集，而同一台机器 `tesseract --list-langs` 明明列出两个语言。另：`hasTesseract()` 找不到可执行文件时是**抛异常**不是返 false | `2f0cbce` |
| B6 | 健康指示器编译不过 | Boot 4 把健康 API 搬到了 **`org.springframework.boot.health.contributor`**；旧路径 `…actuate.health` 只剩端点内部实现 | `8934d7c` |
| B7 | ★★ **OCR 出来的中文被逐字打散**（`某 某 集团`），打穿 L1/L2 锚点 | chi_sim 把**每一个汉字**识别成一个 `ocrx_word`（实测 133 word / 133 字），Tika 把它当 XHTML 事件流发出时词间成了空白。`preserveInterwordSpacing=false` **救不回来**（只作用于 TXT 路径）⇒ 走 `12 §11.4` 预留的退路：**自解析 hOCR** | `2f0cbce`，**未修完** → T249.1 |

## C 类：失败信息在撒谎 —— 把"没做 / 写错"说成"服务器崩了"

| # | 现象 | 根因 | 现状 |
|---|---|---|---|
| C1 | 未实现的端点报 **500「服务内部错误，请把时间反馈给管理员」** | `/segments/batch-move` 被 `GET /segments/{id}` 的模式吃掉（占位符吃到 `batch-move`）⇒ `HttpRequestMethodNotSupportedException` 落进兜底 handler。**「路径认识、方法不对」和「路径都不认识」是两件事** | ✅ 映射成 **405 + 可用方法** · `ac90e9a` |
| C2 | 非法状态转移报 500 | 状态机抛的消息**本来就是写给用户看的**（「当前状态是「成功」，不允许…」），落进兜底 | ✅ `400 + 原文` · `0.3.0` |
| C3 | 非法 UUID / 非法 JSON 报 500 | 同上，都继承 `Exception` ⇒ 被 `@ExceptionHandler(Exception.class)` 抢先 | ✅ 显式映射 400（历史） |
| C4 | `/segments/batch` 报「参数类型不正确：id」 | 被 `DELETE /segments/{id}` 吃掉，把"功能没做"说成"你传错了" | ✅ 落字面量路由 · `36151eb` |
| C5 | 界面一族按钮点了报 **404「接口不存在」** | 文档改名 / 启停 / 删除、库级重算、分段启停 / 重向量**后端根本没有端点** —— 而 404 看起来像环境问题、不像功能没做 | ✅ 补齐 7 个端点 · `ac90e9a` |

**判据**：**把包络里的文案念一遍** —— 如果一句话出现在"这个功能还没做"的现场，而它说的是
「服务内部错误，请反馈给管理员」，那它就是这一类。兜底 `@ExceptionHandler(Exception.class)`
会把**一切 4xx 语义**改写成 500，所以"调用方能自己修的问题"必须在它之前有显式映射。

## D 类：会静默留下错数据的语义坑

| # | 动作 | 不做会怎样 | 现状 |
|---|---|---|---|
| D1 | **改名** | 结构化前缀里含文档名 ⇒ 只改聚合根会留下「文档叫 A、分段的检索文本里写着 B」：按新名字**召回不到**，而两处各自看起来都正常 | ✅ 重写全部分段 `search_text`/`content_hash` + 标向量过期 |
