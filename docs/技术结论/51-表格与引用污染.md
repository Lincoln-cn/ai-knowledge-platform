## 六、新发现（★ 只记账不改码；处置建议待合并时定）

### 发现① Tika 把表格竖线转义成 `\|` ⇒ 表格块识别与改写接缝整体失效

- **链条**：Tika 解析产物表格行形如 `\| Name \| Dept \|`（以反斜杠开头）→
  `MarkdownChunker.isTableRow` 只认**裸** `|` 开头（`MarkdownChunker.java:264-266`：
  `line.stripLeading().startsWith("|")`）→ `readTable`（`:216`）从不触发 →
  表格行走 `readParagraph` 文本路径 → `is_table=false`（实测两份夹具 0 段）→
  `Segmenter.java:227,234` 的 `tableRewriter.rewrite` 对非表格块不改写 →
  **`search_text` 里进的是原表转义文本，不是「列名：值；列名：值」行级陈述**（实测行级陈述 0 行）。
- **危害**：表格的向量检索与全文索引拿不到行级陈述（列名+值的自然语句），表格问答召回质量退化；
  引用侧 `content` 保留原表（这点尚可）。这是**静默失效**（无报错、无读数报警）。
- **最小复现**：`.build/51_segment_probe.py`（`is_table` 全 0、行级陈述 0 行）+
  `.build/seg-dump.txt`（段 #0 `s4-s7`、段 #1 `s2-s5` 原样 `\|` 表格文本）。
- **可能的改法方向**（供选择，不代做）：`isTableRow`/`isSeparatorRow` 同时认 `\|` 转义
  （或入口统一反转义归一）。

### 发现② 规则③（跨页重复行）误伤同构重复表格的表头与分隔行

- **读数**：§3.1/§3.2 的 B 夹具 6 行（表头 3 + 分隔 3）在生产档被剥、`keepDesignLines=true` 全回来。
- **危害**：多页同构表格（人事实例表、流水表）跨页重复表头本是表格语义的一部分，被当页眉剥掉 ⇒
  引用缺列名（与 #51"引用"判据直接相关）。
- **最小复现**：`.build/51_noise_counterproof.py`（A/B 两档对照）。
- **可能的改法方向**：重复行剥离跳过表格行（或先切表格块、再跑噪声规则）。

### 发现③ 重叠前缀拼接少一个换行 ⇒ 粘连行

- **链条**：`MarkdownChunker.overlapInto` 的 `joined = tail + curr.content()`
  （`MarkdownChunker.java:445`）——`extractOverlapTail` 取的 `tail` 不以换行结尾 ⇒
  前一段尾句与当前段首行**粘连**。实证：A 段 #1 content 首行
  `The third table lists the approval workflow steps.\| Step \| Owner \| Days \| Doc \|`。
- **危害**：行形态破坏（表头行不再是独立行）；若粘连跨到表格行，任何按行处理的下游都会失灵。
- **最小复现**：`.build/51_dump_seg.py` 输出的 `.build/seg-dump.txt`。
- **可能的改法方向**：`joined = tail + "\n" + curr.content()`（或 `tail` 补行界）。

## 八、踩的坑

1. **audit 初版分隔行判定写错**：`set(ln.replace("|","").strip()) <= {"-",":"}` 把空格算进字符集
   ⇒ 分隔行归不进类、全被算成表头。改为 `re.fullmatch(r"\s*\|(\s*:?-{2,}:?\s*\|)+\s*", ln)`，
   表头改按位置判（分隔行的上一行）。**判据**：分类判定要用 `fullmatch`，不要用字符集 `set` 去猜。
2. **空 `Authorization: Bearer ""` 头导致登录 401**：`POST /auth/login` 不该带 Authorization 头
   （带空凭证被认证过滤器直接拒）。接口本身正常（`curl.exe` 实测拿到 token）。
3. **pwsh 的 `NativeCommandError` 包装误报**：`python -c` 把版本行写到 stderr 时 pwsh 会包装成
   `[exit code: 1]`，其实是正常输出——长脚本一律先写 `.py` 再跑（任务书同款纪律）。
4. **psql 输出含多行字段**（`content`/`search_text` 有换行）⇒ 必须 `\copy … to stdout with csv header`
   + python `csv` 模块解析，不能按行 split。
