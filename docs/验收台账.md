> 这份表只回答一件事：**今天能不能说"可用"**。
> 判据本身写在 `docs/ROADMAP.md` §二（2.1 三场景 / 2.2 A1–A9 / 2.3 B1–B7），这里逐个记「读数 / 出处 / 还差什么」。
>
> **状态只有三档**，且必须与证据同时改：
>
> - ✅ **有当前读数**：证据是一条能跑的测试/脚本，或一次带 run 链接的 CI；
> - 🟡 **有零件、缺整链**：零件能跑，但它证明的不是这一条；
> - ⬜ **无读数**：只有设计或代码，没有任何东西能证明它成立。
>
> 三条纪律：**不写推断**（"应该可以"不是读数）· **零件不等于判据**（A2 的浏览器脚本跑通 ≠ 全链路刷新不重置）· **改状态必须换证据**（只改 emoji 不算）。
